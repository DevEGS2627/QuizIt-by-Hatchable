EGS Quizit!

Operator guide

A quick runbook for running the event without turning the quiz into an IT incident.

Before the event

  1. Open Admin Controls while signed in as the project owner or an admin collaborator.
  2. Edit the six placeholder teams and add school names and logo URLs.
  3. Import questions with the CSV template linked below. Required columns are tag, round, question_text, and answer_text. Each tag must be unique, and rounds must be 1–6.
  4. Confirm scoring values and the timer duration, then save settings.
  5. Open Presentation mode and test the projector, timer, audio, and answer reveal before the audience arrives.

Download question CSV template

During the quiz

  1. Choose the active round in Live Quiz.
  2. Use Reveal tag for a physical chit or Draw random to select an unused question.
  3. Read the question aloud or use browser speech synthesis. Start, pause, or reset the timer as needed.
  4. Use Register pounce before awarding a pounce result. Regular correct/wrong scoring is restricted to the question owner.
  5. Use Stats to review standings and export score or history CSV files.

Visibility and access

The project starts private. In the Hatchable console, open project Settings and change visibility to public if the audience must access the scoreboard without signing in. Keep admin write endpoints protected. Admin actions require the project owner or an admin collaborator to be signed in.

This build uses Hatchable PostgreSQL and Hatchable collaborator access for the backend. It does not connect to a separate Supabase project. Team logo and media fields currently accept URLs; direct file uploads are not implemented in this version.

Important notes

  • The question CSV import accepts up to 500 rows per batch. Large banks can be split across multiple imports.
  • Use a recent Chrome or Edge browser for presentation and speech synthesis.
  • Test the network and projector before the event. A local/offline-only mode is not implemented in this hosted version.
  • Score reset removes score rows but records an audit entry first. Resetting draw eligibility preserves draw history.
